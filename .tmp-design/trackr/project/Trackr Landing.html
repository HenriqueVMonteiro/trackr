Rápido como pensar

Cada ação é um atalho. Criar, transicionar, comentar, atribuir — tudo sem tirar as mãos do teclado e sem esperar a tela recarregar.

  • ✓ Paleta de comandos em tudo
  • ✓ Navegação 100% por teclado
  • ✓ Zero spinners — interface instantânea

Um fluxo que faz sentido

Status são uma máquina de estados visual e clara — não um labirinto de workflow schemes. Todo mundo entende para onde a issue pode ir, e por quê.

  • ✓ Transições válidas sempre à vista
  • ✓ Regras de aprovação embutidas
  • ✓ Activity log completo de cada mudança
Backlog → Todo → In progress → In review → Done
In review → Done exige aprovador definido
